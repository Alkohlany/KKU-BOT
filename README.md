# KKU Bot - بوت جامعة الملك خالد

بوت تيليجرام احترافي لإدارة وحماية قروبات جامعة الملك خالد.

## المميزات

- إدارة القروبات والردود التلقائية
- حماية القروبات من المعلنين والحسابات المزعجة
- نظام حظر متقدم
- قاعدة بيانات PostgreSQL
- سجل النشاطات

## التشغيل

### محلياً

```bash
pip install -r requirements.txt
python -m bot.main
```

### باستخدام Docker

```bash
docker-compose up -d
```

## المتطلبات

- Python 3.10+
- PostgreSQL
- توكن بوت تيليجرام

## المتغيرات البيئية

| المتغير | الوصف |
|---------|-------|
| BOT_TOKEN | توكن البوت |
| CHANNEL_ID | معرّف القناة |
| CHANNEL_LINK | رابط القناة |
| DATABASE_URL | رابط قاعدة البيانات |
| ADMIN_IDS | معرّفات المشرفين (مفصولة بفاصلة) |
